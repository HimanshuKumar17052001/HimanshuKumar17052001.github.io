How to interpret these maps

Each screenshot has measured DOM coordinates for visible headings, project illustrations, metrics, and prominent links. A soft emphasis region is drawn around each element. Its weight is clamp(font-size / 100, 0.25, 1) for page content, and clamp(font-size / 80, 0.3, 1) for dialog headings and actions. The footprint depends on the element’s width and height. Overlapping regions accumulate. Colours indicate that drawing’s intensity, not a probability of looking or clicking.

This intentionally simple model does not understand task intent, colour contrast, image semantics, reading direction, visitor attention, or business outcomes. Large text will be emphasised by construction. The maps help locate competing visual elements; the review and browser checks determine whether useful content and actions are reachable. Changing the overlay does not change the underlying screenshot.
